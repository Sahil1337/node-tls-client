## HeaderInput

The type of every `headers` option.

```ts
type HeaderInput = Record<
  string,
  string | number | readonly string[] | null | undefined
>;
```

Numbers are sent as strings, arrays are joined with `", "`, and `null` or `undefined` removes the header. That's useful in request options to drop one session header. See [Headers](/guides/headers).
